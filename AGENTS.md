# Frontend changes

All frontend changes must support both light and dark themes. Do not design or verify only one theme.

- Reuse the existing theme tokens and shared component styles. Check text contrast, surfaces, borders, buttons and all relevant interaction/feedback states in both themes.
- Verify affected screens in both themes before release, including desktop and mobile where the layout is responsive. Switching themes must not leave stale colors or unreadable content.
- Record both-theme verification in the release notes. Do not claim visual acceptance from a single-theme screenshot.

This requirement was confirmed by the site administrator on 2026-09-12.
