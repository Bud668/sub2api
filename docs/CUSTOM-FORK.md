## 主要差异

- 用户模型使用规则：未设置的用户和模型默认允许；明确设置的模型可以禁止、不限量或按请求数限制。所有 Key 共用该用户的模型额度，模型别名归一后共用计数。
- 每日额度按 `Asia/Shanghai` 零点重置；保留按小时窗口。数据库原子预占，未执行请求按证据退回；改规则不清空当前窗口。新站点不会静默切换分组权限来源，需管理员显式激活用户规则。
- HTTP 与 WS 首帧/续轮共用准入；重连不能绕过额度，同一请求的上游重试不重复预占。额度拒绝可见于错误记录，归类为本地业务限制，不计为上游故障或 cyber 违规。
- 安全审计保留脱敏、长度约束、管理员权限与读取留痕。关键词拦截和上游 `cyber_policy` 分开处置；会话屏蔽与停用待人工复核的开关由运营者配置。上游策略命中不是人工认定违规的证据结论。
- 批量模型选择使用内嵌复选框，支持搜索、全选搜索结果；添加按钮突出显示。保存显示进行中、成功或失败，成功后保留窗口与服务端返回的规则供核对。
- 认证缓存失效等待已排队的本地删除完成，避免早先排队的 Set 短暂重新出现；本地调用、Pub/Sub 和后台失效任务使用同一入口。正常读取路径不增加等待。
- 可选的跟随上游动态订阅额度：固定来源、按权重分配、原生 7d 阈值、可信容量与候选容量隔离，只有来源重置证据确认后才换周期。详见 [动态订阅](DYNAMIC-SUBSCRIPTIONS.md)。
- 账务恢复保留冻结定价凭证，扣款、用量与结算原子去重；证据不足的订阅费用按规则标记站点承担，订阅管理显示笔数、已确认金额及未知笔数，支持当前/历史明细。上游确认重置按来源归档，不向新周期追扣。
- WS 上游空闲时继续处理保活帧，透传首字逐轮独立记录，保留现有推理/工具输出口径；不保证所有请求的首字或总耗时更短。
- 渠道状态的用量窗口显示请求数、Token、账号费用 A、用户费用 U、百分比与重置倒计时；OpenAI 的 5h/7d 预计总费用沿用账号页口径。用户页面默认约 30 秒刷新，当前用量按关联账号共享 30 秒本地缓存，独立于历史探活快照；页面和定时检测附带的 OpenAI 额度读取均不发送上游请求。百分比来自账号已采集的窗口数据，账号管理页面无需保持打开。状态、对话延迟与 Ping 仍由管理员配置的探活周期决定。沿用服务端配额可见性开关；读取失败不伪造零费用。预计费用是按当前账号费用和未取整百分比外推的参考值，不是上游保证的总额度。

认证修复针对已排队的本地写入，不意味着已经在途的请求可以被撤回，或多实例、Redis 故障与所有跨进程并发已经具有强一致性保证。上游已有的持久化失效队列、重试及二次失效仍保留。

## 隐私与范围

启用审计的站点，管理员可能依据配置读取命中请求的脱敏摘录及关联元数据。脱敏不能保证移除所有个人信息；保留期限、管理权限和用户告知必须由运营者明确设置。不要把不可信普通用户提升为管理员来查看上游账号。

公开仓库不包含真实配置、数据库备份、用户邮箱/用量、请求正文、服务器地址清单、SSH/云凭据、Bot Token 或内部运行手册。测试使用模拟数据。独立 TG 通知器属于单独部署组件，不是本源码内默认开启的功能；其运行配置也不在这里。

## 受控构建

需要 Linux、Git、Bash、jq、Go 1.27.0、Node v20.19.2、pnpm 9.15.9，以及专门用于测试的 PostgreSQL。工具链版本以发行清单为准。仅运行 `go build` 不等于通过发布验收。

1. 检出待验证的完整源码提交或发行标签，核对来源。
2. 在隔离 PostgreSQL 创建 **sub2api_modelquota_test** 库；测试会创建/删除临时 schema，严禁指向业务库。使用关键词 DSN，不使用 URL。
3. 从模板生成临时候选清单，填入当前源码提交、版本及 UTC 构建时间。也可以使用发行附件中对应提交的清单，以复现该版本。

```bash
git clone https://github.com/Bud668/sub2api.git
cd sub2api
# 复现指定发行版时，先 git checkout 对应标签。
upstream_tag=$(jq -r .upstream_tag deploy/custom-release.example.json)
git fetch --no-tags https://github.com/Wei-Shaw/sub2api.git "refs/tags/$upstream_tag:refs/tags/$upstream_tag"
source_commit=$(git rev-parse HEAD)
build_date=$(date -u +%Y-%m-%dT%H:%M:%SZ)
jq --arg source "$source_commit" --arg date "$build_date" \
  '.source_commit=$source | .commit=$source | .build_date=$date' \
  deploy/custom-release.example.json > /受控路径/candidate.json
export SUB2API_MODEL_QUOTA_TEST_DSN='host=/隔离数据库socket目录 port=55438 user=postgres dbname=sub2api_modelquota_test sslmode=disable'
bash tools/build-managed-release.sh "$PWD" /不存在的构建目录 /受控路径/candidate.json
```

脚本从指定提交创建干净 worktree，执行安全、WS、额度数据库/竞态、前端语言与界面回归，再构建内嵌前端的二进制；失败即退出，不部署、不修改业务库。产物包括源码归档、基线差异、候选清单和校验值。使用相同源码、锁文件和工具链便于复核；未声称所有环境下均已证明逐字节可复现。

本仓库启用只读的 `Custom release regression` CI，调用同一构建入口，不持有生产凭据、不自动发布或部署。继承的官方构建 CI/自动发布流程只允许在官方仓库运行，保留文件便于对照；依赖安全扫描另外保留并启用，不自动延长上游遗留例外的有效期。功能回归通过不代表依赖扫描或第三方审计通过。

上线须另外审查迁移与兼容性、备份、核对安全停转锁、处理在途连接，再验证真实入口与自然请求。主备使用同一产物，备机不自动启动或恢复数据库。检查源码不需要任何生产凭据。
